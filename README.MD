# miWatermark

一个用 Python 实现的“仿小米风格”照片大水印工具，支持：

- **命令行批量处理**（`批量加大水印.py`）
- **PyQt5 图形界面拖拽处理**（`仿小米水印界面版.py`）

项目会读取 JPG 照片的 EXIF 信息（机型、时间、光圈、快门、ISO、GPS），并在原图下方扩展区域生成大水印后输出新图。

---

## 功能特性

- 支持单张 JPG 处理与文件夹批量处理。
- 自动读取并使用 EXIF 信息：
  - 相机/手机型号
  - 拍摄时间
  - 光圈、快门、ISO
  - GPS（若无则使用自定义文案）
- 支持白色或黑色水印底。
- 支持切换 Logo（小米 / 莱卡 / 苹果 / 其他）。
- 输出时尽量保留 EXIF 信息。

## 使用说明

### 1) 命令行版本（批量/单图）

运行：

```bash
python 批量加大水印.py
```

程序会提示输入路径：

- 输入 **文件夹路径**：会处理该目录下所有 `.jpg` 文件，并输出到同级新目录 `原目录名加水印`。
- 输入 **单张 `.jpg` 文件路径**：会在同目录输出 `原文件名-加水印.jpg`。

> 注意：当前脚本默认只匹配小写 `.jpg`，不包含 `.jpeg` 或大写扩展名。

---

### 2) 图形界面版本（拖拽）

运行：

```bash
python 仿小米水印界面版.py
```

在 GUI 中：

1. 选择水印颜色（白色/黑色）。
2. 选择 Logo（小米/莱卡/苹果/其他）。
3. 可选输入自定义相机名。
4. 可选输入地点文案（无 GPS 时显示）。
5. 将 JPG 文件或文件夹拖拽到窗口中进行处理。

---

## 参数行为说明

核心处理函数为 `add_watermark(...)`，关键参数语义如下：

- `jpg_file`：`[目录, 文件名]`
- `camera_name`：自定义机型名（可覆盖 EXIF 机型）
- `black`：是否黑底水印（`True` 黑底白字，`False` 白底黑字）
- `is_img`：是否单图输出模式
- `place`：无 GPS 时显示的默认地点文案
- `logo`：Logo 文件名（位于 `watermark/` 下）

---

## 已知限制

- 仅处理 `.jpg` 文件（当前逻辑未覆盖 `.jpeg`/`.png`）。
- 字体路径写死为 Windows 字体目录（如 `C:\Windows\Fonts\msyhbd.ttc`），在 Linux/macOS 上可能报错，需要改为本机字体路径。
- 当图片 EXIF 关键信息缺失时，脚本会跳过该文件并提示“获取的参数不全”。
- ISO 文案当前拼写为 `IOS`（来自现有代码逻辑）。
